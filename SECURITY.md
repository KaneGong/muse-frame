# Security

Please avoid public reports containing credentials, tokens, private images or exploitable details. If private vulnerability reporting is enabled, use https://github.com/KaneGong/muse-frame/security/advisories/new. If that option is unavailable, open a minimal Issue requesting a private contact channel without disclosing the vulnerability itself.

This is a single-user local application. Do not bind it to a public network or treat it as a multi-user hosted service. Platform credentials belong to the user and should never be bundled or included in public diagnostics.

This preview has functional checks, not an independent security audit or guaranteed response SLA.

安全问题请勿在公开Issues中泄露凭据、私人图片或可直接利用的细节。优先使用启用后的私密漏洞报告入口；不可用时仅请求私密联系方式，不公开漏洞内容。当前测试不等于独立安全审计，也没有承诺响应时限。
