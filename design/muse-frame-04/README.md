# Muse Frame · Design 06 作品工具版

2026-11-09 素材重制与遗漏核对原型。保留已认可的图库人物，主穿搭改为细条纹西装、阔腿裤；按不同用途搭配夏季、针织、冬装与晚装。环境按真实场所重做为无人单画幅照片。姿态继续按动作归组、卡内切换视角。

Mac 双击 `启动原型.command`，需要本机 Python 3。默认打开 `http://127.0.0.1:9002/`。也可运行 `python3 launch.py`。服务仅监听本机；不停止其他应用。Design01—05 和原工作台数据不受影响。

## 2026-11-10 作品查看与基础修图

点击中央作品可无边框查看；滚轮缩放、左键按住拖动，Esc退出。基础修图含旧版实际12项：曝光、对比、高光、阴影、白色阶、黑色阶、冷暖、色偏、饱和、清晰度、纹理、锐度；支持前后对照、重置、调色预设与自定义预设。

修图在本机处理实际像素，保存为独立版本，原图保留；下载PNG使用源图尺寸。预览可缩小，不会用预览替换导出。空间滤波与旧Pillow实现不同，不宣称逐像素复刻。浏览器存储容量不足时会提示，可直接下载；正式测试版仍需接入原图文件持久存储和真实任务。原预设分类管理与回收站未迁入。

## 2026-11-10 取景照片补齐

“这张怎么拍 → 画面怎么取”的5个常用选项与“更多取景”的12项均使用照片，新增11张并复用1张已审核全身图。照片保持同一人物、灰色西装和连廊，说明取景范围、画面位置与留白。独立放大只查看，不采用；选择只修改当前镜头，不替换人物、服装或环境。横幅示例不自动切换整组画幅。

沿用9002和Design06存储键，用户已有设置保留。原交付保留，真实生成仍为演示。

## Design06 素材轮内容

36 套拍法；9 类、46 种空间与 118 个背景变化；14 种光影、12 种取景、12 种神态；8 组共 77 项细节。旧版 24 个场所归入统一选择器，可按旧名称搜索；自填继续保留。

154 张不同 AI 示例：36 套拍法各一张首图、118 个环境变化各一张背景图。封面复用对应首图，不重复计数。图片详情保留完整构图。整套其他镜头、光影与妆发对比图仍待补，不能据此称为全部素材完成。

本轮补回单项重置、逐张反差/景深/质感、解除人物/服装引用、恢复移除镜头、重开比较记录、复制当前提示词与打包下载样例。环境动作提示按实际图片中的座位、通道校准。

## 使用范围

- 人物、服装、姿态图库的公开目录与所选图片真实按需联网读取，不登录账户、不批量下载原图。
- 预设、逐张设置、版本、保存复用在本机原型内操作。上传内容仅保存在当前浏览器，不是永久备份。
- 所有示例都明确标注为 AI 图。商品示例不是实际商品资料或还原合格证明。
- 生成、改图、任务与平台状态仍为演示，设置变化不会产生真实新照片。真实连接、恢复、模型加载和平台切换尚未迁入本原型。
- Design01 保留商家与研究流程的旧设计示例，与本页数据不互通；不能当作真实批量上新已经完成。
- 与真实旧版的完整差异表、素材覆盖清单、来源与验证记录随交付提供。
