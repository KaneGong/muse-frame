# Muse Frame · Design 01

2026-11-09 的独立界面与流程原型。用于检验新的产品结构、操作流程和状态规则；不是日常使用版，不接入原工作台数据。

Mac 双击 `启动原型.command`。需要本机 Python 3；页面在 `http://127.0.0.1:8997/`。也可执行 `python3 launch.py`。仅本机访问，不调用第三方服务。再次启动会复用相同原型服务，不停止其他应用。

四个入口：工作台、素材、拍法、作品。同一次拍摄提供方案、图片、研究视图。支持人物创作、自由安排、研究复用、商品批次与逐项核对；任务与平台状态是演示。

## 使用范围

- 生成、换装、返修重复使用展示样例，不体现修改后的实际画面。
- 上传仅保存在当前浏览器当前地址；支持 JPEG/PNG/WebP，单张 2 MB 内。清理浏览器存储、换浏览器或换端口会影响记录的可见性。上传量较大时浏览器容量有限，保存失败会提示。
- 试用说明里可下载试用记录或重置本原型。下载记录仅作留档；当前没有导入恢复功能。
- 样例原图与清单可实际打包下载。比例选择是裁切预览，不生成多比例派生文件。
- 模型名称、参考数量上限和连接故障均为演示设定，不代表 Lovart/LibTV 的真实能力或费用。
- 商品审核和研究结论用于试操作；演示通过不证明实物准确或拍法在真实模型上适用。

## 开发验证

```sh
node --test design/muse-frame-next/tests/*.test.mjs
```

模型状态测试和 jsdom 事件流程测试分别记录；真实浏览器检查另见交付检查报告。程序运行本身不依赖 npm。原工作台后端、数据库、登录与收费生成未改动。
