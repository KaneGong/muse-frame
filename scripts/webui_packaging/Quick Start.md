# 映象所 · Muse Frame 0.6

Mac Apple Silicon 用户请打开 DMG、把 Muse Frame 拖入「应用程序」，再双击打开。Windows x64 用户双击 Setup.exe；安装器会为当前用户安装程序并打开浏览器。两种安装包均自带运行环境。Mac 包为临时签名，未获 Apple 公证。Windows 安装器未签名，系统可能提示或限制打开。受管理的电脑请遵循管理员的安装策略。

首页可继续已有拍摄、制作人像和商品套图、上传修图，或导入 Agent 制作的镜头计划。正式工作区沿用 MUSE FRAME 用户资料目录，浏览器默认使用本机 9014 端口。平台按用户自己的账户计费，在最终确认页检查图片、模型和数量。更换版本前请等任务完成，通过「工作区迁移与备份」退出旧服务。

On Apple Silicon, open the DMG and drag Muse Frame into Applications. On x64 Windows, open Setup.exe. The runtime is included. The Mac app is ad-hoc signed and unnotarized. Windows Setup is unsigned.
