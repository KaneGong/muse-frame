# 隐私与数据流

映象所在本机运行，仅监听本地回环接口。项目、提示词和已下载图片在本机保存；Mac版在自己的应用数据目录保存平台授权。全新安装不会自动导入其他软件账号。

平台授权会访问平台登录服务；提交生图或修改时，所选参考图与提示词会发送到对应平台，适用平台自己的政策。在线图库会向作者源站请求目录、缩略图及所选原图。点击项目源码链接会访问GitHub。

此预览版未加入项目维护者的统计上报、自建账号注册服务或计费后台。外部平台、GitHub和图库源站仍可能获取相应网络请求信息；生成并非全流程离线，也不能宣称所有参考图始终只留本机。

导出和诊断可能含照片、提示词或项目标识。分享前请自行检查。请勿向公开Issues上传令牌文件、完整应用数据目录或私人照片。完整备份含授权信息，也需妥善保护。
