# 隐私与数据流

映象所只监听本地回环地址。拍摄、提示词和下载图片保存在你的电脑上。Mac 和 Windows 的 WebUI 安装版在当前系统用户自己的资料目录中保存平台授权，连接账号由你发起。工作区迁移和应用内备份会排除平台凭据。

授权时，由平台的授权服务处理登录流程。提交生图或修改时，所选参考图和提示词会发送至对应平台，适用平台自身的规则。在线图库会向各自源站请求目录、缩略图和所选原图。点击仓库链接会访问 GitHub。

账号授权与生图由对应平台处理。平台、GitHub 和图库源站可能获取各自处理的网络请求信息。

导出文件和诊断可能含有照片、提示词或项目标识。分享前请自行检查。授权文件和手工备份的完整资料目录请私密保存。[快速开始](quick-start.md)列出资料位置和工作区备份入口。
