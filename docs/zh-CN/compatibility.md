# 兼容与预览版限制

- 当前下载包要求macOS 26及以上，为Apple Silicon arm64 Mac版，临时签名、未公证。
- 包内原生库要求最低macOS 26.0，已据此修正App声明。本次实测环境为macOS27.0.1/arm64，其他版本与干净设备仍待验证；旧系统可尝试使用兼容Python依赖运行源码WebUI。
- 尚未发布或实机验收Intel Mac和Windows安装包。
- 源码WebUI是本机单用户服务，没有公网多租户账户、隔离与计费能力。
- Lovart/LibTV先前各通过一次隔离4张并行生成，Lovart另通过一次文字修改；不等于所有模型、账号、地区、异常和参数组合都通过。
- 比例与分辨率按平台模型目录提供；平台未声明的参数不能保证可用。
- 英文界面已提供，用户原文不翻译；部分连接状态、诊断、内置提示词及上游图库内容仍是中文。
- 人物占比百分比是近似提示词要求，不能保证精确构图；身份、姿态及参考一致性也可能因模型而变化。
- 图库速度与可用性依赖作者源站。最多10张选择后逐张导入，失败时保留剩余选择。
- 当前不含外部识图模型反推、涂抹蒙版修改、应用内收费和赠送平台额度。
- WebKit可能把缩放后的JPEG解码尺寸当作naturalWidth（问题325301）；本机原图使用已校验的尺寸标注与实际像素缩放，预览不套用任务原图尺寸。
- 多镜头列表在较矮窗口中常驻摘要较高，必要时滚动使控件露出；此布局体验继续收集反馈。
